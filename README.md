# Order History Export

Chrome extension by [517 Industries](https://ko-fi.com/U7U5S8FW4). Export your Amazon order history (orders, items, payments, shipments) to CSV or JSON from the signed-in Chrome session.

Local only. No Amazon password. Nothing is uploaded.

## Install (unpacked)

1. Chrome → `chrome://extensions`
2. Enable Developer mode
3. Load unpacked → select the `extension` folder

## Privacy

This extension reads Amazon order pages in your already-signed-in session and stores the last export plus an invoice cache in `chrome.storage.local` on this computer.
