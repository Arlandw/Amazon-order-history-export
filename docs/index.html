Privacy

Order History Export is published by 517 Industries.

Order History Export runs entirely in your browser.

What it reads

Order history pages on Amazon sites you choose, using the session where you are already signed in. It never asks for your Amazon password.

What it stores

Your last export, UI preferences, and a local invoice cache stay in Chrome’s extension storage on this computer. The cache is only used to skip re-downloading invoices you already exported. You can clear it from the popup. Nothing is uploaded.

What it does not do

  • No analytics or tracking
  • No remote servers
  • No sale or sharing of order data

Uninstalling the extension deletes the locally stored report.
